A hosted, multi-tenant web app that automated a tedious daily task for sellers on a resale marketplace. A user could sign up, connect their account, set a schedule, and subscribe. 

Behind that sat real authentication, Stripe billing with webhooks, encrypted credentials, background jobs that survived deploys, and a verification system that caught silent failures the platform's API did not report.

I built it with Claude Code, learning Railway, Supabase, Resend, FastAPI, and Stripe as I went, then ran a small beta.
