Command reference for the ADE command-line tool. The reference has a single source of truth and is updated automatically, so it never drifts from the shipped commands.

The content comes from a `help.json` file in the [ADE CLI repository](https://github.com/landing-ai/ade-cli) that the tool itself generates. A GitHub Action and a Python script pull that file into the docs whenever the CLI changes.
